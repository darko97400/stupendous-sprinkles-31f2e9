# Reign of Heroes — Weekly hero artwork v2

Full-bleed localized cartoon illustrations for the native Unity Choose frame, with the title painted into the image (no separate Unity labels).

- `week-00-fr.png` through `week-11-fr.png`: **4 HÉROS GRATUITS CETTE SEMAINE**.
- `week-00-en.png` through `week-11-en.png`: **4 FREE HEROES THIS WEEK**.
- The 12-week cycle begins Monday 2026-01-05 00:00 UTC and matches `HeroRotationV341` exactly.
- `manifest.json` version 2 lists each cycle, language, stable hero IDs and SHA-256 digest. Unity rejects a manifest that changes the gameplay rotation.
- The illustration fills the complete picture surface (1.144534:1), with scenic safe areas beneath the native frame relief.
- A matching bundled image is available offline. GitHub failure never blocks the main menu.
- Four weekly heroes and Meta-owned durable heroes are playable; unowned heroes outside the rotation have a padlock in Choose. Artwork does not grant ownership.

The previous `v1` folder remains available to older builds.
